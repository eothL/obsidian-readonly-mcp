# Allowed And Excluded Obsidian Commands

## Included

The MCP server includes read-only wrappers for:

- `aliases`
- `backlinks`
- `base:query`
- `base:views`
- `bases`
- `bookmarks`
- `commands`
- `daily:path`
- `daily:read`
- `deadends`
- `dev:console` without `clear`
- `dev:css`
- `dev:dom`
- `dev:errors` without `clear`
- `diff`
- `file`
- `files`
- `folder`
- `folders`
- `help`
- `history`
- `history:list`
- `history:read`
- `hotkey`
- `hotkeys`
- `links`
- `orphans`
- `outline`
- `plugin`
- `plugins`
- `plugins:enabled`
- `properties`
- `property:read`
- `random:read`
- `read`
- `recents`
- `search`
- `search:context`
- `snippets`
- `snippets:enabled`
- `tabs`
- `tag`
- `tags`
- `tasks` listing only
- `template:read`
- `templates`
- `theme`
- `themes`
- `unresolved`
- `vault`
- `vaults`
- `version`
- `wordcount`
- `workspace`
- `workspaces`
